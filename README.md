Experimental Artifact Tangler (exp_arctan)
=====================================================


What was (and for now still is) the part of [sboxU](https://github.com/lpp-crypto/sboxU) that deals with fancy display, and tangling a markdown into a program that generates a coherent transcript.

Work in progress, don't try to use it (yet).

## Installation

```sh
pip install pip install git+https://github.com/lpp-crypto/exp_arctan.git
```
